
## 设计风格指南

**整体风格**：

- 配色方案：主色调蓝色(#1976D2)，辅助色橙色(#FF9800)，强调色红色(#F44336)
- 设计风格：扁平化、简洁现代
- 字体：微信默认字体，标题16pt，正文14pt，辅助文字12pt
- 图标：线性图标，统一风格，蓝色为主
- 内边距：统一16px

## 页面结构与布局

### 一、用户端页面

#### 1. 首页 (Home)

**布局结构**：

- 顶部：搜索栏 + 门店信息条（地址+电话）
- 中部：大型轮播图(Banner)展示洗车服务
- 核心操作区：两个主要按钮"预约洗车"和"现场下单"（大按钮，并排放置）
- 服务项目区：网格展示服务类别（精致洗车、内饰清洁等），每个项目包含图标+文字
- 底部：订单查询入口 + 我的订单入口

**关键组件**：

- 门店信息条：左侧地址图标+简短地址，右侧电话图标（可点击拨打）
- 大型服务按钮：宽度100%-32px，高度72px，圆角8px，内含图标+文字
- 底部Tab栏：首页、订单、我的（微信小程序标准底部导航）

#### 2. 预约下单页 (Appointment)

**布局结构**：

- 顶部：步骤指示器（4步：选择服务→选择时间→填写信息→支付确认）
- 内容区：根据当前步骤动态显示不同表单
- 底部：操作按钮（下一步/上一步/提交）

**步骤页面设计**：

1. **选择服务页**：
   - 服务卡片列表（每个卡片：图片、服务名称、简介、价格、勾选框）
   - 底部：已选服务总价格展示
2. **选择时间页**：
   - 日期选择器（日历形式，显示7天可选日期）
   - 时间段选择（显示可预约时段，如9:00-10:00，不可约时段置灰）
3. **填写信息页**：
   - 车辆选择（下拉选择已有车辆或添加新车）
   - 车辆信息表单（车牌号、车型、颜色）
   - 备注信息文本框（选填）
4. **确认支付页**：
   - 订单信息汇总（服务项目、时间、车辆信息）
   - 价格明细
   - 支付按钮（微信支付图标）

#### 3. 订单列表页 (OrderList)

**布局结构**：

- 顶部：状态筛选标签栏（全部、待到店、等待服务、洗车中、已完成）
- 内容区：订单卡片列表
- 无订单状态：居中显示"暂无订单"图示

**订单卡片组件**：

- 订单号+下单时间
- 服务类型图标+名称
- 状态标签（不同状态不同颜色：待到店-橙色、等待服务-蓝色、洗车中-绿色、已完成-灰色）
- 车牌信息
- 右侧箭头（可点击进入详情）

#### 4. 订单详情页 (OrderDetail)

**布局结构**：

- 顶部：订单状态大字体展示+回退按钮
- 进度条组件（横向4步骤指示器，当前步骤高亮）
- 订单信息区：订单号、车牌号、服务项目、价格、下单时间
- 门店信息区：地址、联系电话
- 底部：根据订单状态显示不同按钮（如"取消预约"、"联系门店"）

**进度条组件详细规格**：

- 横向排列4个圆形节点，节点间连线
- 每个节点下方小字标注状态名称
- 已完成节点填充蓝色，当前节点边框高亮，未完成节点置灰
- 节点下方显示对应状态的时间（如已到这一步）

### 二、门店端页面

#### 1. 门店订单管理页 (StoreOrderList)

**布局结构**：

- 顶部：状态筛选标签+新增现场单按钮
- 内容区：订单列表（与用户端类似，但每个订单卡片增加操作按钮）
- 搜索框：支持订单号/车牌搜索

**订单卡片（门店版）**：

- 内容与用户端相似
- 增加订单类型标识（预约/现场）
- 根据当前状态增加操作按钮：
  - 待到店状态→"确认到店"按钮
  - 等待服务状态→"开始洗车"按钮
  - 洗车中状态→"洗车完成"按钮

#### 2. 新建现场单页 (NewStoreOrder)

**布局结构**：

- 表单布局：车牌输入框、服务选择区、备注区
- 底部：提交按钮

**关键组件**：

- 车牌输入组件（模拟车牌输入键盘）
- 服务选择列表（同预约页的服务选择）
- 价格计算区

#### 3. 门店订单详情页 (StoreOrderDetail)

**布局结构**：

- 与用户端订单详情相似
- 增加客户信息区
- 底部操作区更大，根据订单状态显示不同按钮

## 核心组件详细规格

### 1. 进度追踪组件 (OrderProgress)

**设计规格**：

- 组件宽度：100%-32px
- 高度：120px
- 4个圆形节点（直径24px）：待到店→等待服务→洗车中→可取车
- 节点连接线：2px宽，灰色底色，已完成部分蓝色
- 每个节点下方：状态名称+时间戳（小字体）
- 当前状态：节点边框高亮+粗体文本
- 已完成状态：节点填充蓝色+勾选图标
- 未完成状态：节点空心灰色

### 2. 订单卡片组件 (OrderCard)

**设计规格**：

- 卡片宽度：100%-32px，高度：自适应
- 背景色：白色，边框：1px浅灰，圆角：8px
- 内边距：16px
- 包含元素：
  - 订单号（左上）+订单时间（右上，灰色小字）
  - 服务名称（粗体）+价格
  - 车牌号（灰色小字）
  - 状态标签（右下角，不同状态不同色）
  - 用户端：无按钮
  - 门店端：底部有状态转换按钮

### 3. 服务选择卡片 (ServiceCard)

**设计规格**：

- 卡片宽度：100%-32px，高度：80px
- 左侧：服务图标（48px×48px）
- 中间：
  - 服务名称（粗体16pt）
  - 简短描述（灰色14pt）
  - 价格（橙色16pt）
- 右侧：复选框/单选框

### 4. 状态筛选标签栏 (StatusFilter)

**设计规格**：

- 水平滚动条
- 每个标签：文字+数字，如"待到店(3)"
- 标签宽度：根据内容自适应，内边距：水平12px，垂直8px
- 选中状态：底部蓝色条状指示，文字加粗
- 未选中：灰色文字

## 用户流程与交互

### 1. 预约流程

**页面流：**

1. 首页 → 点击"预约洗车"
2. 选择服务页 → 选择需要的服务 → 点击"下一步"
3. 选择时间页 → 选择日期和时间段 → 点击"下一步"
4. 填写信息页 → 填写/选择车辆信息 → 点击"下一步"
5. 支付确认页 → 确认订单信息 → 点击"支付"
6. 支付成功页 → 显示成功提示，可查看订单

### 2. 现场下单流程（门店端）

**页面流：**

1. 门店订单列表 → 点击"新建现场单"
2. 填写车牌 → 选择服务 → 点击"提交"
3. 确认订单 → 收款 → 完成下单
4. 返回订单列表，新订单状态为"等待服务"

### 3. 订单状态流转（门店端）

**交互流程：**

1. 预约单到店：
   - 门店订单列表 → 找到"待到店"状态订单 → 点击"确认到店"
   - 状态变为"等待服务"
2. 开始服务：
   - 找到"等待服务"状态订单 → 点击"开始洗车"
   - 状态变为"洗车中"
3. 完成服务：
   - 找到"洗车中"状态订单 → 点击"洗车完成"
   - 状态变为"可取车/已完成"

## 状态与提示设计

**各状态颜色编码：**

- 待到店：橙色 #FF9800
- 等待服务：蓝色 #1976D2
- 洗车中：绿色 #4CAF50
- 可取车/已完成：灰色 #9E9E9E

**按钮状态设计：**

- 默认状态：蓝色背景，白色文字
- 点击状态：深蓝色背景
- 禁用状态：浅灰色背景，深灰色文字
- 危险操作（如取消）：红色背景或红色文字

**提示设计：**

- 成功提示：绿色背景Toast，显示2秒
- 错误提示：红色背景Toast，显示2秒
- 确认操作：弹出Modal确认框，包含取消和确认按钮

## 示例页面原型描述

**为了更好理解，下面是一个具体页面的详细原型描述：**

### 订单详情页原型详述：

- 顶部：白底，标题"订单详情"居中，左侧返回箭头
- 状态区：背景色随状态变化，高度80px，状态名称居中大字体(20pt)
- 进度条组件：4个圆圈节点，水平排列。已完成节点填充蓝色+白色对勾，当前节点蓝色环形+白底，未完成节点灰色环形+白底。节点下方状态名称+时间(如有)
- 订单信息区域：白卡片
  - 顶部灰色横条"订单信息"
  - 字段竖排：订单号、下单时间、车牌号、服务项目、金额
  - 每项为"字段名称：字段值"格式
- 门店信息区域：白卡片，包含地址和电话
- 底部：
  - 用户端待到店状态：显示"取消预约"按钮（红色边框）
  - 用户端其他状态：显示"联系门店"按钮（蓝色）
  - 门店端：根据状态显示"确认到店"/"开始洗车"/"洗车完成"按钮（蓝色）

------

**注意事项：**

1. 所有页面需保持设计风格一致性
2. 确保交互流程连贯
3. 状态颜色编码一致
4. 所有按钮、输入框等控件使用圆角设计
5. 订单状态转换需清晰直观
6. 用户端与门店端保持视觉风格统一但功能有明确区分
