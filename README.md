# 车服务微信小程序

基于微信小程序云开发的汽车服务预约和管理系统。

## 开发环境

- 微信开发者工具：最新版
- Node.js：12.x 或以上
- 云开发环境：cloud1-0grrc4znc15e5fde

## 目录结构

```
carshop/
  ├── cloudfunctions/         # 云函数目录
  │   ├── login/              # 登录相关
  │   ├── user/               # 用户信息管理
  │   └── database/           # 数据库初始化
  ├── miniprogram/            # 小程序端代码
  │   ├── pages/              # 页面
  │   ├── assets/             # 资源文件
  │   └── utils/              # 工具函数
  └── project.config.json     # 项目配置
```

## 首次部署步骤

1. 创建云开发环境

   - 打开微信开发者工具
   - 点击"云开发"按钮
   - 创建一个新的云开发环境或使用已有环境 (cloud1-0grrc4znc15e5fde)

2. 部署云函数

   - 在`cloudfunctions`目录下右键每个云函数文件夹
   - 选择"上传并部署：云端安装依赖"
   - 确保所有云函数都成功部署

3. 初始化数据库

   - 部署完`database`云函数后
   - 打开云开发控制台
   - 进入云函数页面
   - 测试运行`database`云函数，参数为: `{"action": "initCollections"}`
   - 检查运行结果，确保所有集合创建成功

4. 配置云存储
   - 在云开发控制台中创建`services`文件夹
   - 上传服务相关图片到此文件夹

## 云函数部署故障排除

如果云函数上传失败，可能有以下原因：

1. 网络问题：确保网络连接稳定

2. 权限问题：

   - 确保已登录微信开发者工具
   - 检查是否有足够的云开发权限

3. 依赖安装问题：

   - 尝试在本地安装依赖后再上传：
     ```
     cd cloudfunctions/[function-name]
     npm install
     ```
   - 然后选择"上传并部署：不安装依赖"

4. Node.js版本问题：

   - 云函数使用Node.js 10.x运行
   - 避免使用不兼容的语法或API

5. 文件大小问题：

   - 确保云函数文件大小不超过限制
   - 避免添加不必要的依赖

6. 云环境问题：
   - 确保云环境ID正确配置
   - 确保云环境未超过资源配额

## 数据库集合

项目使用以下数据库集合：

1. `users` - 用户信息
2. `vehicles` - 用户车辆信息
3. `services` - 服务项目
4. `appointments` - 预约信息
5. `orders` - 订单信息
6. `payments` - 支付记录
7. `coupons` - 优惠券
8. `notifications` - 通知消息

## 开发注意事项

1. 云开发资源有使用限制，注意控制API调用频率
2. 敏感信息不要硬编码在小程序中
3. 所有数据库操作尽量通过云函数进行，避免在小程序端直接操作数据库
4. 用户鉴权信息只能通过云函数的context获取，确保安全性
